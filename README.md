### Repository with slides and demo projects

There are different accompanying Demo Projects available.

Each project has a more detailed project description, inside the top folder of that project.
You can find the following demo projects:
* [demo-10-simple-vaadin14-java8](demo-projects/demo-10-simple-vaadin14-java8)
  * Probably not too interesting for you, but for me it was the starting point. 
  * See the README at [demo-10-simple-vaadin14-java8](demo-projects/demo-10-simple-vaadin14-java8) for details.
* [demo-15-simple-vaadin25-java21](demo-projects/demo-15-simple-vaadin25-java21)
  * This demo project is the starting point and I use it in my talk to explain the fundamental working principle of the framework.
  * See the README at [demo-15-simple-vaadin25-java21](demo-projects/demo-15-simple-vaadin25-java21) for details.
* [demo-20-better-vaadin25-java21](demo-projects/demo-20-better-vaadin25-java21)
  * This demo project is still a single gradle project and pushes the concept a little further.
  * Mainly I tried to prepare the project for being a framework. So it can be seen as an intermediate step in that direction.
  * See the README at [demo-20-better-vaadin25-java21](demo-projects/demo-20-better-vaadin25-java21) for details.
* [demo-30-framework-vaadin25-java21](demo-projects/demo-30-framework-vaadin25-java21)
  * This project divides the original sources into three (gradle) sub-projects and adds a Spring Boot AutoConfiguration.
  * See the README at [demo-30-framework-vaadin25-java21](demo-projects/demo-30-framework-vaadin25-java21) for details.
